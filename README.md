# Authorized OWASP Juice Shop Security Lab

## Scope

This repository contains documentation and evidence from an
authorized security assessment of a local OWASP Juice Shop instance.

Authorized target:

http://localhost:3000

Only the local intentionally vulnerable lab was tested.

## Out of Scope

- Production systems
- Public websites
- Third-party systems
- Other computers or network hosts
- Real user accounts or personal data

## Documentation

- Asset Inventory
- Data Flow Diagram
- STRIDE Threat Model
- Rules of Engagement

## Security Tests

- T-01: Scope Validation
- T-02: SQL Injection Observation
- T-03: Authorization Validation
- T-04: XSS Validation
- T-05: Information Exposure Observation

## Evidence

Evidence is stored in the `Evidence` directory and supporting
screenshots are stored in the `Screenshots` directory.

Testing was limited to the authorized local laboratory environment.
No destructive testing or intentional data modification was performed.
